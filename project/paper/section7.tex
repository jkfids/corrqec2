\section{Quantum cellular automaton model}\label{sec:qcamodel}
In this section, we introduce a spatiotemporal SPP model. We construct a microscopic two-dimensional coherent quantum cellular automaton (QCA) on a bath, locally coupled to system qubits, plus repeated `classicalisation' via system twirling which induces a probabilistic cellular automaton (PCA) with a nonlinear kernel \(p = \sin^2(k\theta)\) depending on the number of excited neighbours. The result is a physically derived spatiotemporal SPP, that remains efficient to simulate and sample, while exhibiting nontrivial correlation structure and statistical mechanical properties controlled by few parameters.

\subsection{Quantum cellular automaton}\label{sec:qca-details}
We now specify the microscopic dynamics defining the quantum cellular automaton (QCA) noise model. The joint evolution is constructed by composing several maps. First a local ``storm'' channel on the environment, in direct analogy with temporal storm model in \cref{sec:temporalstormmodel}; second, a two-layer coherent QCA update on the environment lattice; and third, a local system-environment interaction. For each cycle, the system-environment dynamics are twirled on the system degrees of freedom, corresponding to multi-time Pauli twirl mapping general dynamics to an SPP. Under the conditions stated later in this section, the system twirl induces an effective dephasing channel on the environment in each cycle. This re-classicalisation is the key mechanism that allows the reduced dynamics to be described exactly as an effective probabilistic cellular automaton (PCA) HMM.

The geometry and initial conditions are as follows. Let \(\{S_i\}\) be system qubits arranged on a finite 2D square lattice, intended to model a surface code patch, including data and syndrome qubits. To each \(S_i\), we associate a single environment qubit \(E_i\), such that the environment lattice inherits the system's adjacency structure. We bipartition the environment lattice into red and black sublattices \(E = E_\mathrm{red} \cup E_\mathrm{black}\), corresponding to a chequerboard pattern, such that each red environment qubit neighbours only black environment qubits and vice versa. Before any dynamics, we take the environment qubits to initialise as a classical mixture of \(Z\)-basis states, where \(\rho_{E_i}\) diagonal is in \(\{\ket{0}, \ket{1}\}\), and hence initially uncorrelated with the system.

The entire dynamics are governed by three parameters. Two temporal parameters \((a, b)\) specify the local environment storm channel \(\mathcal{E}^E (a, b)\) as in \cref{sec:temporalstormmodel}. A third spatial parameter \(\theta\) controlling the QCA update on the environment, implemented via half-steps \(\mathcal{V}_{R\to B}^E(\theta)\) and \(\mathcal{V}_{B\to R}^E(\theta)\). Writing \(\mathcal{U}^{SE}\) for the system-environment unitary interaction, we define the joint single cycle CPTP map as the composition
\begin{equation}
    \Phi_{a, b, \theta} \coloneq \mathcal{U}^{SE} \circ \mathcal{V}_{B\to R}^E(\theta) \circ \mathcal{V}_{R\to B}^E(\theta) \circ \mathcal{E}^E (a, b).
\end{equation}
We detail each component map below.
\begin{enumerate}
    \item \textbf{Environment storm channel}, \(\Phi^E(a, b)\)
    
    Each environment qubit undergoes an independent storm channel that flips each qubit from \(\ket{0}\) to \(\ket{1}\) with probability \(a\), and from \(\ket{1}\) to \(\ket{0}\) with probability \(b\). Concretely, this is the CPTP map
    \begin{equation}
        \Phi^E(a, b)[\rho] = \sum_\alpha K_\alpha \rho K_\alpha^\dagger,
    \end{equation}
    with Kraus operators,
    \begin{equation}
            K_0 = \sqrt{a}\ketbra{1}{0}, 
            \quad K_1 = \sqrt{1-a}\ketbra{0}{0}, 
            \quad K_2 = \sqrt{b}\ketbra{0}{1}, 
            \quad K_3 = \sqrt{1-b}\ketbra{1}{1}.
    \end{equation}

    \item \textbf{QCA half-step (red \(\to\) black)}, \(\mathcal{V}_{R\to B}^E(\theta)\)
    
    The QCA update on the environment is implemented as a two-layer controlled unitary circuit, with the red and black sublattices as alternating control and target layers. The rotations are along the \(X\) axis with angle \(\theta\). For the first half-step, define the unitary
    \begin{equation}
        V_{R}(\theta) = \prod_{i\in E_\mathrm{red}} \prod_{j\in N(i)}
        \left(
            \ketbra{0}{0}_{E_i} \otimes I_{E_j} + \ketbra{1}{1}_{E_i} \otimes e^{-i\theta X_{E_j}}
        \right).
    \end{equation}
    This is a product of commuting controlled \(X\) rotations with red qubits as the controls and black neighbours as targets. The corresponding channel is
    \begin{equation}
        \mathcal{V}_{R\to B}^E(\theta)[\rho] = V_R(\theta) \rho V_R(\theta)^\dagger.
    \end{equation}

    \item \textbf{QCA half-step (black \(\to\) red)}, \(\mathcal{V}_{B\to R}^E(\theta)\)
    
    Similarly, define the unitary for the second layer with black qubits as controls and red neighbours as targets as
    \begin{equation}
        V_{B}(\theta) = \prod_{i\in E_\mathrm{black}} \prod_{j\in N(i)}
        \left(
            \ketbra{0}{0}_{E_i} \otimes I_{E_j} + \ketbra{1}{1}_{E_i} \otimes e^{-i\theta X_{E_j}}
        \right),
    \end{equation}
    and the corresponding channel is
    \begin{equation}
        \mathcal{V}_{B\to R}^E(\theta)[\rho] = V_B(\theta) \rho V_B(\theta)^\dagger.
    \end{equation}
    Together, these two layers implement a full QCA update on the environment update.

    \item \textbf{Environment-system unitary}, \(\mathcal{U}^{SE}\)
    
    At each site \(i\), the environment qubit \(E_i\) couples locally to the system qubit \(S_i\) via a joint unitary \(U_{SE}\), defined as
    \begin{equation}
        U_{SE} = \sum_{k=0}^1 \ketbra{k}{k}_{E_i} \otimes Q_k.
    \end{equation}
    Need \(Q_k\) to be a unitary on the system, satisfying \(Q_k Q_k^\dagger = I \forall k\) and \(\Tr(Q_k Q_l) = 0 \forall k \ne l\).
    % where \(Q_k\) is generally a convex combination of Paulis satisfying \(\alpha_P \ge 0, \sum_P \alpha_P = 1\).
\end{enumerate}
