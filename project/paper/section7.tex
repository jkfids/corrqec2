\section{Quantum cellular automaton model}\label{sec:qcamodel}
In this section, we propose a spatiotemporal SPP model. We construct a microscopic two-dimensional coherent quantum cellular automaton (QCA) on a bath, locally coupled to system qubits, plus repeated `classicalisation' via system twirling which induces a probabilistic cellular automaton (PCA) with a nonlinear kernel \(p = \sin^2(k\theta)\) depending on the number of excited neighbours. The result is a physically derived spatiotemporal SPP, that remains efficient to simulate and sample, while exhibiting nontrivial correlation structure and statistical mechanical properties controlled by few parameters.

\subsection{Quantum cellular automaton}\label{sec:qca-details}
We now specify the microscopic dynamics defining the quantum cellular automaton (QCA) noise model. The joint evolution is constructed by composing several maps. First a local ``storm'' channel on the environment, in direct analogy with temporal storm model in \cref{sec:temporalstormmodel}; second, a two-layer coherent QCA update on the environment lattice; and third, a local system-environment interaction. For each cycle, the system-environment dynamics are twirled on the system degrees of freedom, corresponding to multi-time Pauli twirl mapping general dynamics to an SPP. Under the conditions stated later in this section, the system twirl induces an effective dephasing channel on the environment in each cycle. This re-classicalisation is the key mechanism that allows the reduced dynamics to be described exactly as an effective probabilistic cellular automaton (PCA) HMM.

The geometry and initial conditions are as follows. Let \(V\) denote the set of sites of a 2D square lattice \(V\), and label sites by \(i\in V\). At each site, we associate a system qubit \(S_i\), corresponding to data and ancilla qubits on a surface code patch, and an environment qubit \(E_i\). We fix a chequerboard bipartition of the lattice,
\begin{equation}
    V = V_\mathrm{red} \cup V_\mathrm{black}, \quad V_\mathrm{red} \cap V_\mathrm{black} = \emptyset,
\end{equation}
so that each site has neighbours in the opposite sublattice as 
\begin{equation}
    N(i) \subset V_\mathrm{black} \forall i\in V_\mathrm{red}, \quad N(i) \subset V_\mathrm{red} \forall i\in V_\mathrm{black},
\end{equation}
writing \(N(i) \in V\) for the set of nearest neighbours of \(i\).

Before any dynamics, we take the environment qubits to initialise as a classical mixture of \(Z\)-basis states, where \(\rho^{E_i}\) diagonal is in \(\{\ket{0}, \ket{1}\}\), and hence initially uncorrelated with the system.

The entire dynamics are governed by three parameters. Two temporal parameters \((a, b)\) specify the local environment storm channel \(\mathcal{S}^E (a, b)\) as in \cref{sec:temporalstormmodel}. A third spatial parameter \(\theta\) controlling the QCA update on the environment, implemented via half-steps \(\mathcal{Q}_{R\to B}^E(\theta)\) and \(\mathcal{Q}_{B\to R}^E(\theta)\). Writing \(\mathcal{U}^{SE}\) for the system-environment unitary interaction, we define the joint single cycle CPTP map as the composition
\begin{equation}
    \mathcal{M}_{a, b, \theta} \coloneq \mathcal{U}^{SE} \circ \mathcal{Q}_{B\to R}^E(\theta) \circ \mathcal{Q}_{R\to B}^E(\theta) \circ \mathcal{S}^E (a, b).
\end{equation}
We detail each component map below.
\begin{enumerate}
    \item \textbf{Environment storm channel}, \(\mathcal{S}^E(a, b)\)
    
    Each environment qubit undergoes an independent storm channel that flips each qubit from \(\ket{0}\) to \(\ket{1}\) with probability \(a\), and from \(\ket{1}\) to \(\ket{0}\) with probability \(b\). Concretely, this is the CPTP map
    \begin{equation}
        \mathcal{S}^{(i)}(a, b)[\rho] = \sum_k L_k \rho L_k^\dagger,
    \end{equation}
    with Kraus operators,
    \begin{equation}
            L_0 = \sqrt{a}\ketbra{1}{0}, 
            \quad L_1 = \sqrt{1-a}\ketbra{0}{0}, 
            \quad L_2 = \sqrt{b}\ketbra{0}{1}, 
            \quad L_3 = \sqrt{1-b}\ketbra{1}{1}.
    \end{equation}
    The global channel is the product over sites, \(\mathcal{S}^E(a, b) = \bigotimes_{i\in V} \mathcal{S}^{(i)}(a, b)\).

    \item \textbf{QCA half-step (red \(\to\) black)}, \(\mathcal{Q}_{R\to B}^E(\theta)\)
    
    The QCA update on the environment is implemented as a two-layer controlled unitary circuit, with the red and black sublattices as alternating controls and targets. Targets are rotated along the \(X\)-axis with angle \(\theta\). For the first half-step, for each red site \(i \in V_\mathrm{red}\) and its and black neighbours \(j \in N(i)\subset V_\mathrm{black}\), we define the unitary
    \begin{equation}
        U_{R\to B}(\theta) = \prod_{i\in V_\mathrm{red}} \prod_{j\in N(i)}
        \left(
            \ketbra{0}{0}^{E_i} \otimes I^{E_j} + \ketbra{1}{1}^{E_i} \otimes e^{-i\theta X^{E_j}}
        \right).
    \end{equation}
    This is a product of commuting controlled \(X\) rotations with red qubits as the controls and black neighbours as targets. The corresponding channel is
    \begin{equation}
        \mathcal{Q}_{R\to B}^E(\theta)[\rho] = U_{R\to B}(\theta) \rho U_{R\to B}(\theta)^\dagger.
    \end{equation}

    \item \textbf{QCA half-step (black \(\to\) red)}, \(\mathcal{Q}_{B\to R}^E(\theta)\)
    
    Similarly, define the unitary for the second layer with black qubits as controls and red neighbours as targets as
    \begin{equation}
        U_{B\to R}(\theta) = \prod_{i\in V_\mathrm{black}} \prod_{j\in N(i)}
        \left(
            \ketbra{0}{0}^{E_i} \otimes I^{E_j} + \ketbra{1}{1}^{E_i} \otimes e^{-i\theta X^{E_j}}
        \right),
    \end{equation}
    and the corresponding channel is
    \begin{equation}
        \mathcal{Q}_{B\to R}^E(\theta)[\rho] = U_{B\to R}(\theta) \rho U_{B\to R}(\theta)^\dagger.
    \end{equation}
    Together, these two layers implement a full QCA update on the environment.

    \item \textbf{Environment-system unitary}, \(\mathcal{U}^{SE}\)
    
    At each site \(i\), the environment qubit \(E_i\) couples locally to the system qubit \(S_i\) via a controlled unitary interaction. We define
    \begin{equation}\label{eq:qca-se-unitary}
        U_{SE}^{(i)} = \sum_{k=0}^1 \ketbra{k}{k}^{E_i} \otimes V_k^{S_i}, \quad \mathcal{U}^{SE}[\rho] = U_{SE} \rho U_{SE}^\dagger,
    \end{equation}
    where \(U_{SE} = \bigotimes_{i \in V} U_{SE}^{(i)}\). The key structural assumption is that the conditional unitaries \(\{V_k\}\) are orthogonal under the Hilbert-Schmidt inner product, 
    \begin{equation}\label{eq:se-unitary-condition}
        V_k V_k^\dagger = I \forall k, \quad \Tr(V_k V_l) = 0 \ \forall k \ne l,
    \end{equation}
    so that Pauli twirling on the system induces an effective dephasing channel on the environment in the \(Z\) basis.

    In this work, we specialise to a minimal family of unitaries
    \begin{equation}
        V_0 = I, \quad V_1 = \vec{n} \cdot \vec{\sigma} = n_X X + n_Y Y + n_Z Z, \quad \|\vec{n}\|^2 = 1,
    \end{equation}
    with \(\vec{n} \in \mathbb{R}^3\), satisfying \cref{eq:se-unitary-condition}. The coefficients \(n_X^2, n_Y^2, n_Z^2\) sets the relative probabilities of Pauli emissions induced by the Pauli twirling on the system.
\end{enumerate}
The map \(\mathcal{M}_{a, b, \theta}\) defines the local tensor of the process tensor tensor network describing the full spatiotemporal dynamics. To obtain the local tensor of process tensor tensor network under the mutlti-time Pauli twirl, we apply the local system Pauli twirl supermap \(\mathcal{T}_P^S\) on \(\mathcal{M}_{a, b, \theta}\) on the system subspace only. We define the effective twirled joint map as
\begin{equation}
    \widetilde{\mathcal{M}}_{a, b, \theta} \coloneq \mathcal{T}_P^S[\mathcal{M}_{a, b, \theta}].
\end{equation}
Since the storm channel \(\mathcal{S}^E\) and the QCA operators \(\mathcal{Q}_{R\to B}^E\), \(\mathcal{Q}_{B\to R}^E\) act only on \(E\), they commute with the system-only Pauli conjugation. Consequently, the system twirl may be ``pushed through'' the environment-only maps, so that it suffices to apply twirl the twirl to system-environment interaction \(\mathcal{U}^{SE}\) alone. Defining the twirled interaction as \(\widetilde{\mathcal{U}}^{SE} \coloneq \mathcal{T}_P^S[\mathcal{U}^{SE}]\), we write
\begin{equation}
    \widetilde{\mathcal{M}}_{a, b, \theta} = \widetilde{\mathcal{U}}^{SE} \circ \mathcal{Q}_{B\to R}^E(\theta) \circ \mathcal{Q}_{R\to B}^E(\theta) \circ \mathcal{S}^E (a, b).
\end{equation}
The central mechanism of this model is that, for a system-environment interaction satisfying \cref{eq:qca-se-unitary,eq:se-unitary-condition}, the twirled interaction induces an effective \(Z\)-basis dephasing of the environment in each cycle. More precisely, at each site \(i\) the reduced environment update satisfies
\begin{equation}
    \Tr_{S_i}(\widetilde{\mathcal{U}}^{SE}[\rho_{S_iE_i}]) = \sum_k \ketbra{k}{k}^{E_i} \Tr_{S_i}[\rho_{S_iE_i}] \ketbra{k}{k}^{E_i}.
\end{equation}
As a consequence, although the coherent QCA half-steps can create superposition and coherence in the environment, the environment is re-classicalised at the end of each cycle. This effective map, together with the choice of QCA updates as controlled rotations about the \(X\)-axis, allows us to make the following three statements about the effective dynamics. First, the coherent QCA update induces a nonlinear kernel \(p = \sin^2(k\theta)\), giving the probability that a target side flips as a function of the number of \(k\) excited neighbours in the opposite sublattice. Second, the twirled system-environment interaction re-classicalises the environment via the effective \(Z\)-dephasing as described above. Third, conditional on the environment configuration, the induced system noise is a Pauli channel whose relative weights are set by the coefficients \(n_X^2, n_Y^2, n_Z^2\).

We defer the detailed proof of each of these statements in \Fidel{Appendix~X}. We now summarise the resulting PCA HMM dynamics.

\subsection{Probabilistic cellular automaton}\label{sec:pca-details}
We now summarise the PCA HMM dynamics. Let \(s_{t}(i)\) denote the state of environment site \(i\) at time \(t\). The system Pauli emission pattern during cycle \(t\) is denoted by \(x_t(i)\), and emissions are conditioned on the updated environment configuration \(s_{t+1}(i)\) at the end of the cycle. The PCA HMM dynamics are as follows.

\begin{enumerate}
    \item[0.] \textbf{Initialisation}: Choose an initial distribution $\pi_0$ over configurations $s_0\in\{0,1\}^{|V|}$ and sample $s_{0}\sim\pi_0$.

    \item \textbf{Storm update}: Given \(s_{t}\), generate the intermediate configuration \(s_{t'}\) by updating each site \(i\in V\) independently as
    \begin{itemize}
        \item if \(s_{t}(i) = 0\), set \(s_{t'}(i) \gets 1\) with probability \(a\);
        \item if \(s_{t}(i) = 1\), set \(s_{t'}(i) \gets 0\) with probability \(b\);
        \item else set \(s_{t'}(i) \gets s_{t}(i)\).
    \end{itemize}
    \item \textbf{PCA half-step (black)}: Generate the next intermediate state \(s_{t''}\) by updating each black site \(i\in V_\mathrm{black}\), conditioned on the red configuration as
    \begin{itemize}
        \item for each \(i \in V_\mathrm{black}\), compute the number of excited red neighbours \(k(i) = \sum_{j \in N(i)} s_{t'}(j)\);
        \item set \(s_{t''}(i) \gets s_{t'}(i) \oplus 1\) with probability \(\sin^2(k(i)\theta)\), else set \(s_{t''}(i) \gets s_{t'}(i)\);
        \item for each \(i \in V_\mathrm{red}\), set \(s_{t''}(i) \gets s_{t'}(i)\).
    \end{itemize}
    \item \textbf{PCA half-step (red)}: Complete the PCA step to generate \(s_{t+1}\) as
    \begin{itemize}
        \item for each \(i \in V_\mathrm{red}\), compute the number of excited black neighbours \(k(i) = \sum_{j \in N(i)} s_{t''}(j)\);
        \item set \(s_{t+1}(i) \gets s_{t''}(i) \oplus 1\) with probability \(\sin^2(k(i)\theta)\), else set \(s_{t+1}(i) \gets s_{t''}(i)\);
        \item for each \(i \in V_\mathrm{black}\), set \(s_{t+1}(i) \gets s_{t''}(i)\).
    \end{itemize}
    \item \textbf{Pauli emission}: For each site \(i\in V\), sample the system Pauli emissions \(x_t\) as
    \begin{itemize}
        \item if \(s_{t+1}(i) = 0\), sample \(x_t(i)=I\);
        \item if \(s_{t+1}(i) = 1\), sample \(x_t(i) \in \{X, Y, Z\}\) with probabilities \(n_X^2, n_Y^2, n_Z^2\), respectively.
    \end{itemize}
    The resulting Pauli string \(x_t = \{x_t(i)\}_{i\in V}\) is the noise induced on the system during cycle \(t\).
    \item \textbf{Loop}: Increment \(t\), and repeat steps 1-4 for as many cycles required.
\end{enumerate}
