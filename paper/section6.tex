\Fidel{This section will explore potential applications of SPCs to quantum error correction.
\begin{itemize}
    \item The main application is using SPC tensor networks to ``efficiently'' simulate correlated noise in large-scale QEC simulations''. Some specific details:
    \item Can we map the SPC TN directly to a detector error model? This may enable a robust approach to studying correlated noise in the context of circuit-level noise.
    \item Experiments of interest: surface code stability, Floquet codes.
    \item There is an inherent scaling problem with Monte Carlo sampling QEC experiments, in that the number of samples required to estimate a logical error rate $p_L$ scales as $1/p_L$. This is particularly problematic when $p_L$ is (exponentially) small and/or the noise is very sparse. Some approaches to mitigate this is importance sampling and splitting methods. One lead is using ``normalizing flows''.
\end{itemize}
